Lexift 1.0.1 · Quick guide

Get started with Lexift

Start with three shortcuts.

Download for Windows ↓Windows 10 / 11 · x64

Choose an input method

Korean → Japanese ON / OFF

Korean → Chinese ON / OFF

These are the defaults. Change them in Settings.

01

First launch

  1. Extract the whole ZIP and run Lexift.exe. Keep its module folder alongside it.
  2. Choose your display language, add the input methods you use to Slots, then save your changes.
  3. Japanese conversion needs the Korean and Microsoft Japanese IMEs. Chinese conversion uses the Korean IME and the included dictionary.

Choose its input method and mode, then save your changes.

02

Switch input methods

In the app you want to type in, press Caps Lock + Q. Press a slot number to select it, or use the arrow keys and Enter.

03

Type Japanese or Chinese through Hangul

First set the target input field to the Korean IME in Hangul mode (가).

Turn on → type the Korean pronunciation → choose a candidate

Japanese

와타시→わたし→私

Chinese

니하오→ni hao→你好
  • ↑ ↓ : move through candidates
  • Space / Enter : confirm the selected candidate
  • 1–9 / 0 : choose by number · Esc : close the candidate window

Press the same conversion shortcut again to turn it OFF. Turning on the other mode turns the previous one off.

Use - for Japanese long vowels, for example 코-죠- → こうじょう. This converts pronunciation, rather than translating Korean sentences. Chinese output is Simplified Chinese.

04

Make the shortcuts yours

Open Settings to change these options.

05

When a name is missing

In Custom dictionary, enter a keyword, replacement text and language. Example: 스미네 → 澄音 · Korean–Japanese.

The Defaults button

At the bottom of Settings. After confirmation, it resets shortcuts, display language, startup options, slots and the custom dictionary. Keep a copy of any dictionary entries you need first.

No candidates?

Place the cursor in the input field, check Hangul mode and make sure the feature is enabled. Support varies by app and input field.
