Lexift 1.0.1 · 사용설명서

Lexift, 빠르게 시작하기

단축키 세 개부터 익혀보세요.

Windows용 다운로드 ↓Windows 10 / 11 · x64

입력기 선택

한–일 변환 ON / OFF

한–중 변환 ON / OFF

기본 단축키입니다. 일반 설정에서 바꿀 수 있습니다.

01

처음 실행할 때

  1. ZIP을 모두 풀고 Lexift.exe를 실행하세요. module 폴더도 함께 두세요.
  2. 표시 언어를 고르고, 사용할 입력기를 슬롯에 추가한 뒤 변경사항을 저장하세요.
  3. 일본어 변환에는 한국어·Microsoft 일본어 IME가 필요합니다. 중국어 변환은 한국어 IME와 내장 사전을 사용합니다.

입력기와 모드를 고른 뒤 변경사항 저장을 누르세요.

02

입력기 바꾸기

입력할 창에서 Caps Lock + Q를 누르세요. 번호를 누르면 바로 선택되고, 방향키로 이동한 뒤 Enter로 고를 수도 있습니다.

03

한글 발음으로 일본어·중국어 입력

먼저 대상 입력창을 한국어 IME의 한글 모드(가)로 바꾸세요.

켜기 → 한글 발음 입력 → 후보 선택

일본어

와타시→わたし→私

중국어

니하오→ni hao→你好
  • ↑ ↓ : 후보 이동
  • Space / Enter : 선택한 후보 확정
  • 1–9 / 0 : 해당 번호 확정 · Esc : 후보창 닫기

같은 변환 단축키를 다시 누르면 OFF입니다. 다른 변환 모드를 켜면 이전 모드는 꺼집니다.

일본어 장음은 -로도 입력할 수 있습니다. 예: 코-죠- → こうじょう. 한국어 문장의 뜻을 번역하는 기능은 아닙니다. 중국어 출력은 간체입니다.

04

단축키와 언어를 내 방식대로

일반 설정에서 바꿀 수 있습니다.

05

원하는 이름이 후보에 없다면

사용자 사전에 키워드 · 대치할 텍스트 · 언어를 등록하세요. 예: 스미네 → 澄音 · 한–일.

기본값 버튼

일반 설정 아래에 있습니다. 확인하면 단축키·표시 언어·실행 옵션·슬롯·사용자 사전이 초기화됩니다. 저장된 사전도 삭제되므로 필요한 항목을 먼저 보관하세요.

후보가 안 뜨나요?

입력창에 커서를 두고 한글 모드인지, 기능의 사용 체크가 켜져 있는지 확인하세요. 앱·입력란에 따라 지원 범위가 다릅니다.
