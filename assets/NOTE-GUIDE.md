# Note 작성 방법

`assets/notes.json`만 수정하면 됩니다. 저장소에 커밋하고 푸시한 뒤 GitHub Pages 배포가 완료되면 상단 Note 메뉴에 반영됩니다.

현재 파일의 첫 항목은 작성용 양식입니다. 본문은 미리 작성하지 않았고 `published: false`여서 홈페이지 목록에는 나오지 않습니다.

```json
[
  {
    "id": "2026-10-26-first-note",
    "title": "글 제목",
    "date": "2026-10-26",
    "published": true,
    "content": [
      "첫 번째 문단.",
      "두 번째 문단.\n문단 안에서 줄바꿈."
    ]
  }
]
```

- `id`: 글마다 다른 값. 영문, 숫자, 하이픈 사용을 권장합니다. 기존 글의 id를 유지하면 상세 페이지 주소도 유지됩니다.
- `title`: 목록과 상세 페이지에 표시되는 제목.
- `date`: 작성일. `YYYY-MM-DD` 형식으로 입력하면 화면에는 `YYYY.MM.DD`로 표시됩니다. 날짜가 최신인 글부터 자동 정렬됩니다.
- `published`: `true`면 표시, `false`면 목록과 상세 페이지에 표시하지 않습니다. **저장소와 JSON 파일 자체는 공개되므로 실제 비공개 보관 기능은 아닙니다.**
- `content`: 문단마다 따옴표로 감싸 배열에 넣습니다. 문단 사이에는 빈 줄이 들어갑니다. 한 문단 안의 줄바꿈은 `\n`, 따옴표는 `\"`, 역슬래시는 `\\`로 적습니다. HTML/Markdown은 서식으로 해석하지 않고 원문 그대로 표시합니다.

새 글은 `{ ... }` 항목을 복사해서 배열 안에 추가하세요. 항목 사이에 쉼표를 넣고, 마지막 항목 뒤에는 쉼표를 붙이지 마세요. 작성용 양식을 공개하려면 제목·날짜·본문을 수정하고 `published`를 `true`로 바꾸세요.
